Page looks dark? This dashboard is designed to be viewed in light colours. If it appears dark, your browser’s own dark mode is overriding it.
How to switch it off
  • Samsung Internet: tap the menu (☰) and turn off Dark mode, or go to Settings → Labs and turn on Use website dark theme.
  • Opera: Settings → turn off Force dark pages.
  • Brave: Settings → Appearance → turn off Night mode.
  • Chrome: if you turned on the Auto Dark Mode for Web Contents flag, set it back to Default in chrome://flags.
  • Other browsers: look for “dark mode for websites” or “force dark” in the browser’s settings.

Content is encrypted (AES-256-GCM) and opened only in your browser. The password is never stored. Do not share the password outside the intended audience.
