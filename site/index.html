Page looks dark?

This dashboard is designed for light colours. If it looks dark, your browser’s own dark mode is overriding it.

How to switch it off
  • Samsung InternetMenu (☰) → turn off Dark mode, or Settings → Labs → turn on Use website dark theme.
  • OperaSettings → turn off Force dark pages.
  • BraveSettings → Appearance → turn off Night mode.
  • ChromeIn chrome://flags, set Auto Dark Mode for Web Contents back to Default.
  • Other browsersLook for “dark mode for websites” or “force dark” in settings.

Content is encrypted (AES-256-GCM) and opened only in your browser. The password is never stored. Do not share the password outside the intended audience.
